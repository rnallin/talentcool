# TalentoCost - Guia Completo para Replit

## Configuracao Rapida no Replit

### 1. Criar o Repl
- Template: **Next.js**
- Fazer upload de todos os arquivos do projeto (ou importar do GitHub)

### 2. Variaveis de Ambiente (Secrets)
No Replit, va em **Secrets** (cadeado no painel esquerdo) e adicione:

```
NEXT_PUBLIC_SUPABASE_URL=https://SEU-PROJETO.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...sua-chave-anon
```

Opcionais:
```
SUPABASE_SERVICE_ROLE_KEY=eyJ...chave-service
RESEND_API_KEY=re_...chave-resend
NEXT_PUBLIC_APP_URL=https://SEU-REPL.repl.co
```

### 3. Arquivo .replit (criar na raiz)
```toml
run = "npm run dev"
entrypoint = "pages/index.jsx"

[nix]
channel = "stable-24_05"

[env]
PORT = "3000"

[[ports]]
localPort = 3000
externalPort = 80
```

### 4. Ajustar next.config.js
O Replit usa dominios dinamicos. Substitua o conteudo por:
```js
module.exports = {
  reactStrictMode: true,
  allowedDevOrigins: ['*'],
}
```

### 5. Ajustar porta no package.json
Trocar o script dev para usar porta 3000:
```json
"dev": "next dev -p 3000"
```

### 6. Instalar e rodar
```bash
npm install
npm run dev
```

- Framework: Next.js 16 (Pages Router)

- Styling: Tailwind CSS v4 + globals.css
- Charts: Recharts
- Icons: Lucide React

## UX Patterns

### Autenticacao
- Magic Link via Supabase Auth (sem senha)
- AuthProvider em _app.jsx gerencia estado global
- withAuth(Component) protege paginas (redireciona para /login se nao autenticado)
- useAuth() retorna { user, session, loading, signOut, isAuthenticated }
- Callback PKCE em /auth/callback (troca code por session)
- Timeout de 5s na verificacao inicial de sessao com retry

### Navegacao
- PUBLIC_PATHS: /login, /auth/callback, /landing (sem AppLayout)
- Demais rotas: AppLayout com sidebar + topbar
- Sidebar com 4 itens: Dashboard, Gestao de Vagas, Analise de Custos, Relatorios
- Item ativo: bg-indigo-600 text-white shadow-md
- Sidebar colapsavel (w-60 para w-16)

### Padrao de Pagina Protegida
  import Layout, { PageContainer, PageHeader } from '../components/Layout'
  import { useAuth, withAuth } from '../lib/auth'

  function MinhaPage() {
    const { user } = useAuth()
    return (
      <Layout title="Titulo | TalentoCost">
        <PageContainer>
          <PageHeader title="Titulo" subtitle="..." />
        </PageContainer>
      </Layout>
    )
  }
  export default withAuth(MinhaPage)

- Tabela com colunas: Titulo, Departamento, Nivel, Fase, Salario, Dias Aberto, Acoes

### RLS (Row Level Security)
- vacantes: Politica permissiva (FOR ALL USING true) - permite tudo para testes
- cph_calculations: RLS por user_id (SELECT, INSERT, UPDATE, DELETE)
- users: RLS por id = auth.uid()
- benchmark_data: leitura para todos autenticados

### View
- user_stats: agregacao de cph_calculations por user_id (total, avg_cph, avg_days, savings)

### Setup no Supabase
1. Criar projeto em https://app.supabase.com
2. Ir em SQL Editor -> colar conteudo de db/schema.sql -> Run
3. Copiar URL e Anon Key para as variaveis de ambiente

## Motor CPH (lib/cph-calculator.js)

4 metodologias de calculo:

1. Default: Hard Costs + Soft Costs + Onboarding + Treinamento
2. SHRM: (Salario Anual x 3.5) / Dias Uteis x Dias para Preencher
3. Revenue: Receita Diaria por Funcionario x Multiplicador de Nivel x Dias
4. Hybrid: Revenue Loss + Hard Costs + Onboarding + Overload - Economia Salarial

Constantes:
- Multiplicadores regionais: BR 2.83, AR 1.85, MX 1.45
- Dias uteis/ano: BR 252, AR 248, MX 250
- Multiplicadores por nivel: junior 1.0, pleno 1.3, senior 1.6, lead 2.0, manager 2.3, director 2.8
- Benchmarks por setor: tech 32d, manufacturing 38d, logistics 28d, finance 35d, retail 21d

Recomendacao automatica:
- Junior/Pleno -> Default
- Senior/Lead -> Revenue
- Manager+ -> Hybrid

Funcoes de banco: saveCPHCalculation, getCPHHistory, getCPHCalculationById, getUserStats
